# Demo assets

## wikipedia-session.gif

Recorded on 2026-10-24 using mini-runtime `a98e9d3` and Firefox 157.0.1 as the viewer. The looping GIF shows browsing Wikipedia, searching for Quicksort, leaving an unfinished “Merge” search, closing the viewer tab, reopening the same viewer URL, and continuing to Merge sort. The standalone service stays running throughout.

The recording checks that the runtime process, article URL, search text and scroll position survive reconnection. This is a real screen recording at 1.25× playback, reduced to 960 × 750 at 8 fps, with captions and an opaque mask over the private address bar. Raw footage, profiles, access tokens and diagnostic outputs stay outside the repository.
